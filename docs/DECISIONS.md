# Decisions

| Date       | Decision                                                                                                        | Reason                                                                                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-02 | pnpm workspaces, isolated linker                                                                                | Supported by Expo SDK 57; fall back to `nodeLinker: hoisted` only on a concrete failure.                                                                                          |
| 2026-10-02 | TypeScript pinned to ~5.9                                                                                       | typescript-eslint 8.71 requires `<6.1.0`; npm `latest` is 7.x.                                                                                                                    |
| 2026-10-02 | Expo web `output: "single"` (SPA) + Vercel rewrite                                                              | Static export without per-route SSG; simplest correct Vercel deployment.                                                                                                          |
| 2026-10-02 | `packages/ui` deferred                                                                                          | No second consumer yet; tokens/components live in `apps/client` to avoid a speculative abstraction.                                                                               |
| 2026-10-02 | Shared packages consumed as TS source (`main: src/index.ts`)                                                    | Metro, Vitest and tsup handle TS directly; no build step per package. Server bundler must set `noExternal: [/^@chess\//]` once it imports them.                                   |
| 2026-10-02 | `EXPO_PUBLIC_*` read via literal `process.env.X`                                                                | Expo inlines only literal member access; a default-param `process.env` silently left the URL undefined (found by browser test).                                                   |
| 2026-10-02 | Stockfish as separate native process on the server                                                              | Process boundary; client WASM deferred pending licensing review (stockfish GPL-3.0, stockfish-web AGPL-3.0-or-later).                                                             |
| 2026-10-02 | Server bundles `@chess/*` and `chess.js` (tsup `noExternal`)                                                    | Workspace packages are TS source; without bundling `node dist/main.js` fails to resolve them (found by running the build).                                                        |
| 2026-10-02 | Bot moves computed server-side by a native Stockfish process                                                    | Keeps GPL code out of the client bundle; shared by web/Android/iOS with no per-platform engine; see docs/BOT.md for licensing gate.                                               |
| 2026-10-02 | Bot strength = MultiPV candidate sampling with bounded loss, not random weakening                               | Weak bots make plausible mistakes; deterministic with a seed. Labels are not Elo.                                                                                                 |
| 2026-10-02 | Client-disconnect detection listens to the _response_ close                                                     | `req.raw` emits `close` after the body is read (Node >= 16) and was cancelling every search; regression test uses a real socket.                                                  |
| 2026-10-02 | e2e export runs with `--clear`                                                                                  | Metro's cache reused modules with a stale inlined `EXPO_PUBLIC_API_URL`.                                                                                                          |
| 2026-10-02 | Opening data lives in `packages/openings/data` (not top-level `data/openings`)                                  | Keeps data, generator and tests together; Metro/tsup/Vitest resolve it as a normal package import.                                                                                |
| 2026-10-02 | Opening data generated from the CC0 lichess dataset, not hand-typed                                             | Authoritative ECO codes and 3.8k lines; every line replayed through chess-core; freshness enforced by a test.                                                                     |
| 2026-10-02 | Same-named lines are alternates under a primary                                                                 | Without grouping, families fragmented (eleven "Queen's Gambit Declined" roots; Sicilian 2.Nf3 lines in a second root).                                                            |
| 2026-10-02 | Analysis endpoint is stateless + Redis-cached; review is client-orchestrated                                    | Keeps the server simple and cancellable; the cache absorbs repeated positions. A server-side long-running review job can replace it later without changing the pure `reviewGame`. |
| 2026-10-02 | Review thresholds are explicit, configurable cp-loss bands; accuracy from win-probability loss                  | The brief asks for defined (not "scientific") thresholds; documented in docs/ANALYSIS.md.                                                                                         |
| 2026-10-02 | Bearer access tokens + rotating single-use refresh tokens with reuse detection (30 s grace for concurrent tabs) | Works the same on web/Android/iOS across the Vercel/Render domains without third-party cookies; see docs/AUTH.md for the web-storage trade-off.                                   |
| 2026-10-02 | Hand-rolled SQL migration runner (advisory lock, one transaction per file) instead of an ORM                    | Small, auditable, no extra runtime; migrations run at boot.                                                                                                                       |
| 2026-10-02 | No `openings` / `opening_variations` / `bot_profiles` tables                                                    | Their source of truth is versioned code/data; duplicating it in Postgres would create two sources of truth. Games keep `opening_id/name/eco`.                                     |
| 2026-10-02 | CORS methods are set explicitly                                                                                 | The library default silently blocks PUT/PATCH/DELETE from browsers (found by e2e); preflight tests added.                                                                         |
